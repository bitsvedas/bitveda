Q2. Write an HTML program for both an ordered list and an unordered list.

उत्तर (Answer): बुलेट्स वाली सूची के लिए Unordered List <ul> और नंबर वाली सूची के लिए Ordered List <ol> का उपयोग किया जाता है। दोनों के अंदर items लिखने के लिए <li> (List Item) टैग का उपयोग होता है।

<!DOCTYPE html> <html> <body> <h3>Unordered List (Bullets):</h3> <ul> <li>Apple</li> <li>Mango</li> </ul> <h3>Ordered List (Numbers):</h3> <ol> <li>India</li> <li>Japan</li> </ol> </body> </html>

Q3. Write an HTML program to display an image that links to another website.

उत्तर (Answer): इसे बनाने के लिए हमें <img> (Image) टैग को <a> (Anchor/Link) टैग के अंदर रखना होता है। जब कोई इमेज पर क्लिक करेगा, तो वह href वाली वेबसाइट पर पहुँच जाएगा।

<!DOCTYPE html> <html> <body> <p>Click the Google logo to visit Google:</p> <a href="https://www.google.com" target="_blank"> <img src="https://www.google.com/favicon.ico" alt="Google Logo" width="50"> </a> </body> </html>

Q4. Write an HTML program to create a table with 2 rows and 2 columns.

उत्तर (Answer): Table बनाने के लिए मुख्य रूप से 3 टैग्स चाहिए: <table>, <tr> (Table Row), और <td> या <th> (Table Data/Header)।

<!DOCTYPE html> <html> <body> <table border="1" style="border-collapse: collapse; text-align: center;"> <tr> <th>Name</th> <th>Marks</th> </tr> <tr> <td>Ram</td> <td>57</td> </tr> </table> </body> </html>

Q5. Change a paragraph's text color using Inline CSS and Internal CSS.

उत्तर (Answer): Inline CSS टैग के अंदर style="" के रूप में लिखी जाती है, जबकि Internal CSS <head> में <style> टैग के अंदर लिखी जाती है।

<!DOCTYPE html> <html> <head> <!-- Internal CSS --> <style> .internal-text { color: blue; } </style> </head> <body> <!-- Inline CSS --> <p style="color: red;">This text is Red (Inline CSS).</p> <!-- Using Internal CSS --> <p class="internal-text">This text is Blue (Internal CSS).</p> </body> </html>

Q6. Write a JavaScript program to show a simple welcome alert box.

उत्तर (Answer): User की स्क्रीन पर एक popup message दिखाने के लिए JavaScript के alert() function का उपयोग किया जाता है।

💡 Note: alert() function कोड के निष्पादन (execution) को तब तक रोक देता है जब तक user 'OK' पर क्लिक नहीं करता।
<!DOCTYPE html> <html> <head> <title>Alert Example</title> </head> <body> <h2>Alert Example</h2> <button onclick="alert('Welcome to my Website!');"> Click Me! </button> </body> </html>

Q7. Write a JS program that uses a confirm box to ask "Yes or No" and saves their choice.

उत्तर (Answer): confirm() function एक डायलॉग बॉक्स दिखाता है जिसमें 'OK' और 'Cancel' बटन होते हैं। यह true या false return करता है।

<!DOCTYPE html> <html> <head> <title>Confirm Example</title> </head> <body> <script> function askUser() { let choice = confirm("Do you like programming?"); if (choice == true) { document.write("You clicked Yes!"); } else { document.write("You clicked No!"); } } </script> <button onclick="askUser()">Ask Question</button> </body> </html>

Q8. Write a JS program that prompts the user for their name and greets them.

उत्तर (Answer): User से input (टेक्स्ट) लेने के लिए prompt() function का उपयोग होता है।

<!DOCTYPE html> <html> <head> <title>Prompt Example</title> </head> <body> <script> function greetUser() { let userName = prompt("Please enter your name:"); if (userName != null && userName != "") { document.getElementById("msg").innerText = "Hello, " + userName + "!"; } } </script> <button onclick="greetUser()">Enter Name</button> <p id="msg"></p> </body> </html>

Q9. Write a JS program using an if/else statement to check if a number is positive or negative.

उत्तर (Answer): शर्ते (Conditions) चेक करने के लिए if/else स्टेटमेंट का इस्तेमाल होता है।

<!DOCTYPE html> <html> <head> <title>If-Else Example</title> </head> <body> <script> function checkNumber() { let num = document.getElementById("numInput").value; if (num >= 0) { document.getElementById("res").innerHTML = num + " is Positive."; } else { document.getElementById("res").innerHTML = num + " is Negative."; } } </script> <input type="number" id="numInput"> <button onclick="checkNumber()">Check</button> <p id="res"></p> </body> </html>

Q10. Write a JS program using a loop to print numbers from 1 to 5.

उत्तर (Answer): जब हमें एक ही काम को बार-बार दोहराना हो, तो हम Loops का उपयोग करते हैं। for loop गिनती प्रिंट करने के लिए बेहतरीन है।

<!DOCTYPE html> <html> <head> <title>For Loop Example</title> </head> <body> <script> function printNumbers() { let output = ""; for (let i = 1; i <= 5; i++) { output = output + i + " "; } document.getElementById("loopRes").innerText = output; } </script> <button onclick="printNumbers()">Print 1 to 5</button> <p id="loopRes"></p> </body> </html>
