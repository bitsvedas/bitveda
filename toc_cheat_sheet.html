Deep Definition: Containment

Every Regular language is Context-Free, every Context-Free language is Context-Sensitive, and every Context-Sensitive language is Recursive Enumerable. The inclusion is strict and complete.

RegEx & Identities ✨

Formal Definition

A Regular Expression (RE) describes a Regular Language over an alphabet Σ. It uses operators Union (+), Concatenation (•), and Kleene Star (*).
a* → Kleene Closure: 0 or more occurrences of a. Includes empty string ε.
a+ → Positive Closure: 1 or more occurrences of a. Does not include ε.
Crucial Difference:
a* - a+ = ε (also written as ∧ or NULL)

Algebraic Identities

(a+b)* = (a*+b)* = (a*b*)* = (a*+b*)*
Definitions of Notations
aⁿ aᵐ : Concrete generated string sequences.
a+b* : A Regular Expression representing set {a, ε, b, bb, bbb, ...}.
Regular Grammar: Constrained to rules like S → a | b.

Checking Regularity 🔍

Core Rule of Regularity

Regular Languages possess no memory of past symbols beyond a finite number of active states. If a language requires counting or matching arbitrary values, it is not Regular.
Finite Languages: Always Regular! Can always be mapped by a DFA with finite states.
Infinite Languages: Must be analyzed carefully. Ask: Is memory/counting required?
No Matching: If no comparison is done → Regular. Matching (aⁿbⁿ) is Not Regular.
Arithmetic Checks: If comparisons like a=b, a≠b, a>b, or a<b are done → Not Regular.
Required Memory: Relationships like aⁿbᵐ | a=b+1 require tracking counts → Not Regular.
Non-Linear Power: Power progressions like a^{n²} or a^{2ⁿ} → Not Regular.
Concept: The Pumping Lemma

The Pumping Lemma is a proof tool used to prove a language is not regular. It states that all sufficiently long strings in a regular language can be split into three parts (xyz) where xyⁿz must also belong to the language for all n ≥ 0.

Decidability ⚖️

What is Decidability?

A problem is Decidable if there exists an algorithm (represented by a Turing Machine) that halts on all inputs, returning either 'Yes' or 'No'.
Recursive (Decidable)
A Turing Machine (TM) halts on every input.
Accepts valid strings, explicitly rejects invalid ones.
Never enters an infinite loop.
Recursive Enumerable (RE)
Also known as Turing-Recognizable.
If string is valid → TM halts and accepts.
If string is invalid → TM may halt and reject, or run forever in an infinite loop.
Concept: Halting Problem

The famous Halting Problem (determining if an arbitrary program/TM halts on a given input) is the classic example of an undecidable problem. It is RE but not Recursive.

Normal Forms (CFG) 📐

Why Normalize?

Normalizing simplifies Context-Free Grammars by restricting production rules. This ensures structured, predictable parsing trees (useful for compilers).
Chomsky Normal Form (CNF)
A → a (one terminal)
A → BC (exactly two non-terminals)
Properties:
To derive a string of length n, the number of steps required is always exactly (2n - 1).
Greibach Normal Form (GNF)
A → a (one terminal)
A → a C₁C₂...Cₙ (one terminal followed by variables)
Properties:
Highly efficient because every step of the derivation generates exactly 1 terminal symbol, making it easy to track parsing progress.

Automata & Finite State Machines

1. Theory of Automata

Automata Theory is the study of abstract machines and computational problems that can be solved using these machines. It provides the mathematical foundations for parsing, compiler design, and regular searching.

2. Finite Automata (FA)

A Finite Automaton is a mathematical model of computation consisting of a finite set of states, transitions between those states based on input symbols, and an initial and set of final states. Mathematically represented as a 5-tuple:

M = (Q, Σ, δ, q₀, F)
  • Q: Finite non-empty set of states.
  • Σ: Finite set of input symbols (alphabet).
  • δ: Transition function.
  • q₀: Start/Initial State (q₀ ∈ Q).
  • F: Set of final/accepting states (F ⊆ Q).

3. Transition Diagrams & Tables

Transition Diagram: A directed graph representation of a finite automaton. Nodes represent states, directed edges denote transitions labeled with input symbols, and accepting states are denoted with double circles.

Transition Table: A tabular matrix format mapping current states (rows) and input symbols (columns) to their respective next states.

4. Deterministic Finite Automata (DFA)

In a DFA, for each state and each input symbol, there is exactly one next transition. There are no epsilon (ε) transitions.

DFA Transition Function (δ):
δ : Q × Σ → Q
Example: DFA accepting strings over {a,b} ending in "ab":
Q = {q₀, q₁, q₂}, Start = q₀, Final = q₂.
• δ(q₀, a) = q₁, δ(q₀, b) = q₀
• δ(q₁, a) = q₁, δ(q₁, b) = q₂
• δ(q₂, a) = q₁, δ(q₂, b) = q₀

5. Non-Deterministic Finite Automata (NFA)

In an NFA, for a given state and input symbol, there can be zero, one, or multiple transitions to different states.

NFA Transition Function (δ):
δ : Q × Σ → 2ᴜ (Power set of Q)

6. Eliminating ε-Transitions

To convert an NFA with ε transitions (ε-NFA) to an equivalent standard NFA, compute the ε-Closure of each state.

ε-Closure(q): The set of all states reachable from state q by taking only ε-labeled edges (including q itself).
The new transition function is calculated as:
δ'(q, a) = ε-Closure(δ(ε-Closure(q), a))

7. Conversion from NFA to DFA

Every NFA can be transformed into an equivalent DFA using the Subset Construction Algorithm.

Algorithm Steps:
1. Start with the initial state of the DFA as the subset {q₀}.
2. For each new state subset, find the union of transitions for all symbols in Σ.
3. Add these resulting subsets as new DFA states and repeat until no new states are discovered.
4. Final states of the DFA are any subsets containing at least one final state of the NFA.

8. Minimization of DFA

Minimizing a DFA removes redundant states, producing the smallest possible equivalent DFA. This is achieved via Equivalence Partitioning (or the table-filling method).

Partitioning Algorithm:
1. Split states into two groups: Accepting (F) and Non-accepting (Q - F).
2. Repeatedly split these groups if transitions on any symbol land in different partitions.
3. Stop when no further splits are possible. Merge all remaining states inside each partition group.

Regular Expressions & Transducers

1. Regular Expressions (RE)

Regular expressions are algebraic descriptors used to define the strings within a Regular Language. The base elements are symbols from alphabet Σ, ε (empty string), and ∅ (empty set).

Examples:
• (a+b)* : All strings over {a,b}.
• a(a+b)*b : All strings starting with a and ending with b.
• (aa)* : Strings with an even number of a symbols.

2. Conversion of RE to FA

This is commonly done using Thompson's Construction Algorithm, which recursively builds an equivalent ε-NFA from the base parts of a Regular Expression.

3. Arden's Theorem

Arden's Theorem is a mathematical tool used to find a unique regular expression representing transition systems (converting a transition diagram to an RE).

Theorem Formulation:
If P and Q are regular expressions over Σ, and P does not contain ε, then the equation:
R = Q + RP
has a unique solution given by:
R = QP*

4. Mealy & Moore Machines

These are Finite State Machines with outputs (Transducers):

Moore Machine: Output depends strictly on the current state.
λ : Q → Δ (where Δ is the output alphabet).
Mealy Machine: Output depends on both the current state and input symbol.
λ : Q × Σ → Δ.

5. Mealy / Moore Conversion

Moore to Mealy: Highly straightforward. For each transition, copy the output of the destination Moore state onto the incoming transition edge of the Mealy machine.
Mealy to Moore: If a state in a Mealy machine has incoming transitions with different output symbols, split that state into multiple states in the Moore machine (one state for each unique output symbol).

Context-Free Grammars (CFG)

1. Context-Free Grammar (CFG)

A Context-Free Grammar is used to generate Context-Free Languages. Production rules are restricted such that the left-hand side must always be a single variable.

G = (V, T, P, S)

Rules are of the form: A → α (where A ∈ V and α ∈ (V ∪ T)*).

2. Derivations & Derivation Trees

Leftmost Derivation (LMD): Replacing the leftmost non-terminal variable first in every step of the derivation.

Rightmost Derivation (RMD): Replacing the rightmost variable first.

Derivation (Parse) Tree: A graphic tree representation showing the step-by-step substitution hierarchy. The root is the start variable S, internal nodes are variables, and leaves are terminals.

3. Ambiguity in Grammars

A grammar is Ambiguous if there exists at least one string in the language that has more than one unique parse tree (or leftmost/rightmost derivation).

An Unambiguous grammar guarantees exactly one parse tree for every valid string in the language.

4. Simplification of CFGs

Simplification removes redundant variables and productions without changing the generated language. It involves three primary steps:

1. Eliminating Useless Symbols: Remove variables that cannot generate terminals, or are unreachable from start symbol S.
2. Eliminating ε-Productions: Find all nullable variables and adjust productions to simulate their removal.
3. Eliminating Unit Productions: Remove rules of the format A → B to prevent looping transitions.

5. Chomsky & Greibach Normal Forms

Normalizing sets a clean, mathematical standard for production formats:

Chomsky Normal Form (CNF): All rules are strictly A → BC or A → a. Parses always form binary trees.
Greibach Normal Form (GNF): All rules are of the format A → aα (one terminal followed by zero or more variables). Excellent for left-to-right parsing.

Pushdown Automata (PDA)

1. Pushdown Automata (PDA)

A PDA is essentially an NFA equipped with an auxiliary, infinite LIFO Stack Memory. This allows the machine to recognize nested structures and patterns. Mathematically represented as a 7-tuple:

M = (Q, Σ, Γ, δ, q₀, Z₀, F)
  • Γ: Finite set of Stack alphabet symbols.
  • Z₀: Start stack symbol (Z₀ ∈ Γ).
  • δ: Transition maps Q × (Σ ∪ {ε}) × Γ → 2^(Q × Γ*).

2. PDA Acceptance Methods

There are two equivalent ways a PDA can accept input strings:

Acceptance by Final State: The PDA reads the entire string and lands in an accepting state (q ∈ F), regardless of stack contents.
Acceptance by Empty Stack: The PDA reads the entire string and successfully clears all elements from the stack (reaches null/empty stack), regardless of what state it ends in.

3. Non-Deterministic PDA (NPDA)

Unlike finite automata, Non-deterministic PDA (NPDA) are strictly more powerful than Deterministic PDA (DPDA). DPDAs cannot recognize languages like even palindromes wwᴿ because they cannot guess the midpoint of the string without non-deterministic branching.

4. CFG to PDA Conversion

A Context-Free Grammar can be directly converted into an equivalent single-state empty-stack PDA:

Conversion Steps (Top-Down Parser style):
1. Push start symbol S to stack.
2. If stack top is variable A, non-deterministically replace it with the right-hand side of production A → α.
3. If stack top is terminal a, match it with current input symbol and pop it off stack.

Turing Machines & Computability

1. Turing Machine (TM)

A Turing Machine is the ultimate abstract computing model. It features an infinite read-write tape and a tape head that can move left, right, or stay put. Represented as a 7-tuple:

M = (Q, Σ, Γ, δ, q₀, B, F)
  • B: Blank symbol on tape (B ∈ Γ, but B ∉ Σ).
  • δ: Transition function Q × Γ → Q × Γ × {L, R}.

2. Decidability & Undecidability

A problem is Undecidable if no algorithm can be written to solve it for all inputs in finite steps.

Halting Problem: Determining whether an arbitrary Turing Machine halts on an arbitrary input. (Proved undecidable by Alan Turing).
Rice's Theorem: Any non-trivial semantic property of the language recognized by a Turing Machine is undecidable.

3. Post Correspondence Problem (PCP)

The Post Correspondence Problem is an undecidable decision problem proposed by Emil Post. It involves matching sequence blocks of strings (dominoes).

PCP formulation: Given two lists of strings A = {w₁, w₂, ..., wₘ} and B = {x₁, x₂, ..., xₘ}, is there a sequence of indices i₁, i₂, ..., i₞ such that:
w_{i₁} w_{i₂} ... w_{i₞} = x_{i₁} x_{i₂} ... x_{i₞} ?
