1. JavaScript Introduction

बिना JavaScript (JS) के एक वेबसाइट बिल्कुल एक पुतले (statue) जैसी होती है—सुंदर दिख सकती है, लेकिन कुछ कर नहीं सकती। वेबपेज को Interactive और Dynamic बनाने के लिए हम JS का उपयोग करते हैं। यह बटन्स पर क्लिक, एनिमेशन, और डेटा कैलकुलेशन को संभालता है।

2. <script> Element

HTML फाइल में JavaScript लिखने के लिए हमें <script> टैग की आवश्यकता होती है। आप इसे <head> या <body> के अंत में लगा सकते हैं (body के अंत में लगाना बेस्ट प्रैक्टिस माना जाता है ताकि पेज जल्दी लोड हो)।

<!DOCTYPE html> <html> <body> <h1>My Page</h1> <script> document.write("Hello JS from Aakash!"); </script> </body> </html>

3. Comments (टिप्पणियाँ)

Comments वह कोड है जिसे ब्राउज़र इग्नोर (ignore) कर देता है। इसका उपयोग हम अपने नोट्स बनाने या कोड समझाने के लिए करते हैं।

  • Single Line: // यह एक लाइन का कमेंट है
  • Multi-line: /* यह कई
       लाइन्स का कमेंट है */

4. Variables & Data Types

💡 Tip!
वेरिएबल का नाम हमेशा अर्थपूर्ण (meaningful) रखो, जैसे let age = 20;

प्रोग्रामिंग में Variables कंटेनर (डिब्बे) की तरह होते हैं, जिनमें हम डेटा (जानकारी) स्टोर करते हैं।

JavaScript में वेरिएबल डिक्लेयर (Declare) करने के 3 तरीके हैं:

Keyword Explanation (विवरण) Can Re-assign? (क्या बदल सकते हैं?)
var पुराना तरीका। इसे अब कम यूज़ करते हैं। (Global/Function Scope) हाँ (Yes)
let सबसे अच्छा तरीका! नया स्टैंडर्ड। (Block Scope) हाँ (Yes)
const Constant. एक बार वैल्यू दे दी, तो बदल नहीं सकते। नहीं (No)

Types of Variables (Data Types)

डिब्बे में किस तरह का सामान है?
1. String: टेक्स्ट, हमेशा कोट्स में "Aakash"
2. Number: गणित के नंबर 100 या 10.5
3. Boolean: हाँ या ना (True / False)

Casting Variable (Type Conversion)

कई बार हमें एक टाइप को दूसरे में बदलना पड़ता है। जैसे स्ट्रिंग को नंबर बनाना।

let numStr = "50"; // String let actualNum = Number(numStr); // Cast to Number let strNum = String(100); // Cast Number to String document.write(actualNum + 10); // Output: 60
Browser Output
60

5. Dialog Boxes (Popups)

JavaScript वेबपेज पर यूज़र से बात करने के लिए 3 मुख्य पॉपअप बॉक्स देता है:

🎯 Live Test!
नीचे दिए गए आउटपुट बॉक्स में बटन्स पर क्लिक करके असल में Dialog Boxes चेक करो!
  1. alert(): यूज़र को सिर्फ एक संदेश (message) दिखाने के लिए। इसमें सिर्फ 'OK' बटन होता है।
  2. confirm(): यूज़र से "Yes" या "No" पूछने के लिए। यह true (अगर OK दबाया) या false (अगर Cancel दबाया) रिटर्न करता है।
  3. prompt(): यूज़र से कुछ इनपुट (टेक्स्ट) टाइप करवाने के लिए। यह टाइप किया हुआ टेक्स्ट रिटर्न करता है।

6. Functions (फंक्शन्स)

प्रोग्रामिंग में DRY (Don't Repeat Yourself) का नियम चलता है। अगर आपको एक ही काम बार-बार करना है, तो उस कोड को बार-बार लिखने के बजाय, हम उसे एक **Function** (मशीन) में डाल देते हैं।

Function Diagram:

Input
(Arguments)
e.g., 5, 10
➡
⚙️ Function
Processing Block
e.g., 5 + 10
➡
Output
(Return Value)
e.g., 15

Declaring & Calling a Function

फंक्शन बनाने के लिए function कीवर्ड का यूज़ होता है। फंक्शन तब तक कुछ नहीं करता जब तक उसे Call (बुलाया) ना जाए।

// 1. Function Declaration (बनाना) function addNumbers(a, b) { let sum = a + b; return sum; // Output देना } // 2. Calling Function (इस्तेमाल करना) let result = addNumbers(5, 10); document.write("Total is: " + result);

7. Expressions & Operators

🛠️ Expression vs Statement
Expression हमेशा एक Value निकाल कर देता है (e.g., 5 + 5).
Statement एक एक्शन करता है (e.g., if-else).

JavaScript में वेरिएबल्स के साथ गणित (Math) और लॉजिक लगाने के लिए Operators का उपयोग होता है।

A. Arithmetic Operators (गणित के ऑपरेटर)

Operator Name Example (x=10, y=5) Result
+Addition (जोड़)x + y15
-Subtraction (घटाना)x - y5
*Multiplication (गुणा)x * y50
/Division (भाग)x / y2
%Modulus (शेष/Remainder)x % 31 (10/3 का शेष)
++Increment (1 बढ़ाना)x++11
--Decrement (1 घटाना)x--9

B. Assignment Operators

ये ऑपरेटर राईट साइड की वैल्यू को लेफ्ट साइड वाले वेरिएबल में सेव (assign) करते हैं।

  • = : (Assign) let a = 10;
  • += : (Add & Assign) a += 5; (मतलब a = a + 5)
  • -= : (Subtract & Assign) a -= 2;

C. Logical Operators (तार्किक ऑपरेटर)

ये दो या दो से अधिक Conditions को एक साथ चेक करने के काम आते हैं। इनका रिजल्ट हमेशा True या False आता है।

Operator Description Condition Meaning in Hindi
&& Logical AND (a > 5 && b < 10) "और" - दोनों शर्तें सही होनी चाहिए।
|| Logical OR (a == 5 || b == 5) "या" - दोनों में से कोई एक शर्त सही हो।
! Logical NOT !(a == b) "उल्टा" - अगर True है तो False कर देगा।
let score = 85; let hasPassed = (score > 40); // Expression let isTopper = (score > 80 && score <= 100); // Logical AND document.write("Passed? " + hasPassed + "<br>"); document.write("Topper? " + isTopper);
Browser Output
Passed? true
Topper? true

8. Statements: if, else if, else

जब हमें कोई डिसिशन (Decision/निर्णय) लेना होता है, तब हम if-else का इस्तेमाल करते हैं।

🚦 Signal Logic
Red = Stop (if)
Yellow = Wait (else if)
Green = Go (else)
let marks = 75; if (marks >= 80) { document.write("Grade: A"); } else if (marks >= 60) { document.write("Grade: B"); } else { document.write("Grade: C"); }
Browser Output
Grade: B

9. Loops: for & while

जब आपको कोई एक ही काम बार-बार (repeat) करना हो, तब Loops काम आते हैं।

Start 🏁
⬇
Condition Check 🤔 (e.g., i < 5)
↙ True
Execute Code
& Update (i++)
⬆ (Repeat)
False ↘
Exit Loop 🛑

For Loop: जब आपको पहले से पता हो कि कितनी बार लूप चलाना है।
While Loop: जब तक Condition True है, तब तक लूप चलता रहेगा।

// For Loop Example for(let i = 1; i <= 3; i++) { document.write("For Loop Run: " + i + "<br>"); } // While Loop Example let j = 1; while(j <= 2) { document.write("While Loop Run: " + j + "<br>"); j++; }

For Loop Run: 3

10. Break & Continue Statements

लूप के बीच में अगर कोई ख़ास कंडीशन आ जाए, तो लूप को कण्ट्रोल करने के लिए:

  • break: लूप को तुरंत वहीं रोक देता है और लूप से बाहर निकाल देता है (Emergency Exit 🚪)।
  • continue: सिर्फ उस एक राउंड (iteration) को छोड़ (skip) देता है और लूप अगले राउंड से फिर चालू हो जाता है।
for(let i = 1; i <= 5; i++) { if(i == 3) { continue; // 3 को skip कर देगा } if(i == 5) { break; // 5 पर लूप रोक देगा } document.write(i + "<br>"); }

2
4
