Topic 1: Lists

Lists in Python

पायथन में List सबसे अधिक उपयोग किया जाने वाला डेटा स्ट्रक्चर है। यह विभिन्न प्रकार के तत्वों (Elements) का एक क्रमबद्ध (Ordered) और परिवर्तनशील (Mutable) संग्रह है। लिस्ट के तत्वों को बड़े कोष्ठक Square Brackets [ ] के अंदर कॉमा (,) से अलग करके लिखा जाता है।

  • Ordered Sequence: लिस्ट में तत्वों का एक निश्चित क्रम (Index) होता है। पहला तत्व 0 इंडेक्स पर और अंतिम तत्व -1 इंडेक्स पर होता है।
  • Mutable (परिवर्तनशील): लिस्ट बनने के बाद भी हम उसके तत्वों को बदल सकते हैं, नए तत्व जोड़ सकते हैं या पुराने हटा सकते हैं।
  • Heterogeneous Elements: एक ही लिस्ट के अंदर int, float, str, या एक अन्य list (Nested List) भी स्टोर की जा सकती है।

1.1 Built-in List Methods

पायथन में लिस्ट पर विभिन्न ऑपरेशन्स करने के लिए निम्नलिखित इन-बिल्ट मेथड्स उपलब्ध हैं:

Method Syntax Detailed Explanation in Hindi
1. append() list.append(item) यह मेथड लिस्ट के अंत (End) में केवल एक नया तत्व (Single Element) जोड़ता है। यदि आप इसके अंदर कोई दूसरी लिस्ट पास करते हैं, तो वह पूरी लिस्ट एक सिंगल सब-लिस्ट के रूप में अंत में जुड़ जाएगी।
2. extend() list.extend(iterable) यह मेथड किसी दूसरी लिस्ट या अनुक्रम (Iterable) के सभी तत्वों को एक-एक करके (Individually) वर्तमान लिस्ट के अंत में जोड़ देता है।
3. insert() list.insert(index, item) यह मेथड किसी निश्चित स्थान (Specified Index) पर नया तत्व जोड़ता है। उस स्थान और उसके बाद के सभी तत्व एक स्थान दाईं ओर खिसक जाते हैं।
4. index() list.index(item) यह दिए गए तत्व की पहली उपस्थिति (First Occurrence) का इंडेक्स नंबर लौटाता है। यदि तत्व लिस्ट में मौजूद नहीं है, तो यह ValueError देता है।
5. remove() list.remove(item) यह मेथड दिए गए मान (Value) की पहली उपस्थिति को लिस्ट से हटाता है। यह कुछ भी रिटर्न नहीं करता (None)। यदि मान नहीं मिलता, तो ValueError आता है।
6. pop() list.pop([index]) यह दिए गए इंडेक्स पर स्थित तत्व को हटाता भी है और उसे रिटर्न भी करता है। यदि कोई इंडेक्स न दिया जाए, तो यह डिफ़ॉल्ट रूप से अंतिम तत्व (Last item) को हटाता है।
7. count() list.count(item) यह गिनकर बताता है कि कोई तत्व लिस्ट के अंदर कुल कितनी बार (Frequency) आया है।
8. sort() list.sort(reverse=False) यह मूल लिस्ट के तत्वों को आरोही क्रम (Ascending Order) में व्यवस्थित करता है। यदि reverse=True लिखा जाए, तो यह अवरोही क्रम (Descending Order) में सॉर्ट करता है।
9. reverse() list.reverse() यह लिस्ट के तत्वों के वर्तमान क्रम को उल्टा (Reverse in-place) कर देता है। (यह सॉर्ट नहीं करता, केवल क्रम पलटता है)।
# Complete Demonstration of List Methods: numbers = [10, 20, 30, 20] # 1. append() - Adds a single element at the end numbers.append(40) print("After append(40):", numbers) # Output: [10, 20, 30, 20, 40] # 2. extend() - Adds multiple elements at the end numbers.extend([50, 60]) print("After extend([50, 60]):", numbers) # Output: [10, 20, 30, 20, 40, 50, 60] # 3. insert() - Inserts 15 at index 1 numbers.insert(1, 15) print("After insert(1, 15):", numbers) # Output: [10, 15, 20, 30, 20, 40, 50, 60] # 4. index() and 5. count() print("First index of 20:", numbers.index(20)) # Output: 2 print("Count of 20:", numbers.count(20)) # Output: 2 # 6. remove() - Removes first occurrence of value 20 numbers.remove(20) print("After remove(20):", numbers) # Output: [10, 15, 30, 20, 40, 50, 60] # 7. pop() - Removes and returns element at index 2 (or last if omitted) popped_val = numbers.pop(2) print("Popped value:", popped_val) # Output: 30 print("List after pop(2):", numbers) # Output: [10, 15, 20, 40, 50, 60] # 8. reverse() and 9. sort() numbers.reverse() print("After reverse():", numbers) # Output: [60, 50, 40, 20, 15, 10] numbers.sort() print("After sort() Ascending:", numbers) # Output: [10, 15, 20, 40, 50, 60] numbers.sort(reverse=True) print("After sort(reverse=True):", numbers) # Output: [60, 50, 40, 20, 15, 10]
Exam Question: Difference between append() and extend()

append([4, 5]) पूरी लिस्ट को एक सिंगल तत्व मानकर जोड़ता है (जैसे: [1, 2, [4, 5]], जिससे लंबाई केवल 1 बढ़ती है)। जबकि extend([4, 5]) लिस्ट को खोलकर उसके प्रत्येक तत्व को अलग-अलग जोड़ता है (जैसे: [1, 2, 4, 5], जिससे लंबाई 2 बढ़ती है)।

1.2 List Slicing

किसी बड़ी लिस्ट में से उसके एक छोटे हिस्से (Sub-list) को काटकर निकालने की प्रक्रिया को List Slicing कहते हैं। इसका सिंटैक्स range() जैसा ही होता है:

list_name[start : stop : step]

  • start: वह इंडेक्स जहाँ से स्लाइसिंग शुरू होगी (डिफ़ॉल्ट 0)।
  • stop: वह इंडेक्स जहाँ स्लाइसिंग रुकेगी। stop इंडेक्स वाला तत्व खुद शामिल नहीं होता (हमेशा stop - 1 तक तत्व मिलते हैं)।
  • step: तत्वों के बीच का उछाल या अंतराल (डिफ़ॉल्ट 1)। यदि step = -1 दिया जाए, तो लिस्ट उल्टी दिशा में स्लाइस होती है।
items = ["A", "B", "C", "D", "E", "F", "G"] print(items[1:5]) # From index 1 to 4 -> ['B', 'C', 'D', 'E'] print(items[:4]) # From start to index 3 -> ['A', 'B', 'C', 'D'] print(items[3:]) # From index 3 to end -> ['D', 'E', 'F', 'G'] print(items[::2]) # Every 2nd element -> ['A', 'C', 'E', 'G'] print(items[-4:-1]) # Using negative indices -> ['D', 'E', 'F'] print(items[::-1]) # Reverses the entire list -> ['G', 'F', 'E', 'D', 'C', 'B', 'A']

1.3 List Comprehension

List Comprehension पायथन की एक बेहद शक्तिशाली सुविधा है, जिसकी मदद से हम किसी मौजूदा लिस्ट या अनुक्रम से केवल एक ही लाइन के कोड (Single Line of Code) में एक नई लिस्ट बना सकते हैं। यह सामान्य for लूप की तुलना में छोटा और तेज़ होता है।

new_list = [expression for item in iterable if condition]

# 1. Creating a list of squares from 1 to 5: squares = [x ** 2 for x in range(1, 6)] print("Squares:", squares) # Output: [1, 4, 9, 16, 25] # 2. Filtering only Even numbers from 1 to 10 using List Comprehension: evens = [num for num in range(1, 11) if num % 2 == 0] print("Even Numbers:", evens) # Output: [2, 4, 6, 8, 10] # 3. Converting words to uppercase if length > 3: words = ["cat", "apple", "dog", "mango"] long_words = [w.upper() for w in words if len(w) > 3] print("Long Words:", long_words) # Output: ['APPLE', 'MANGO']

1.4 Copying a List: Shallow Copy vs Deep Copy

पायथन में यदि आप list2 = list1 लिखते हैं, तो नई कॉपी नहीं बनती! दोनों वेरिएबल्स मेमोरी में एक ही लिस्ट (Same Memory Address) की ओर इशारा करते हैं (इसे Aliasing कहते हैं)। यदि आपको वास्तव में एक अलग कॉपी बनानी है, तो पायथन में दो तरीके होते हैं: Shallow Copy और Deep Copy।

Basis 1. Shallow Copy (उथली कॉपी) 2. Deep Copy (गहरी कॉपी)
How to Create list.copy(), list[:] या copy.copy(list) द्वारा। copy मॉड्यूल के copy.deepcopy(list) फंक्शन द्वारा।
Outer List Behavior यह बाहरी (Top-level) लिस्ट के लिए एक नया मेमोरी ऑब्जेक्ट बनाता है। यह बाहरी लिस्ट के साथ-साथ अंदर की सभी सब-लिस्ट्स के लिए भी बिल्कुल नया ऑब्जेक्ट बनाता है।
Nested List (Sub-list) Behavior यदि लिस्ट के अंदर कोई दूसरी लिस्ट (Nested List) है, तो यह उसकी कॉपी नहीं बनाता, बल्कि पुरानी सब-लिस्ट का ही रेफरेंस साझा करता है। यह अंदर की सभी Nested Lists की भी पूरी तरह स्वतंत्र कॉपी बनाता है।
Effect of Modification अंदर की Nested List में बदलाव करने पर मूल (Original) लिस्ट भी बदल जाती है! Nested List में बदलाव करने पर मूल लिस्ट पर कोई प्रभाव नहीं पड़ता (100% Independent)।
import copy # Original Nested List original = [10, 20, [30, 40]] # Creating Shallow Copy and Deep Copy shallow_list = copy.copy(original) deep_list = copy.deepcopy(original) # Modifying the nested element [30, 40] -> changing 30 to 999 shallow_list[2][0] = 999 print("Original after Shallow modification:", original) # Output: [10, 20, [999, 40]] --> Notice: Original also changed! print("Deep Copy remains completely safe:", deep_list) # Output: [10, 20, [30, 40]] --> Deep copy was NOT affected!
Interactive List Slicing Simulator list = [10, 20, 30, 40, 50, 60, 70]
>>> nums = [10, 20, 30, 40, 50, 60, 70] >>> print(nums[1:6:2]) [20, 40, 60]
Topic 2: Tuples

Tuples in Python

Tuple भी लिस्ट की तरह ही विभिन्न डेटा प्रकारों का एक क्रमबद्ध (Ordered) संग्रह है, लेकिन इसकी सबसे बड़ी विशेषता यह है कि यह अपरिवर्तनीय (Immutable) होता है। इसका अर्थ है कि एक बार टपल बन जाने के बाद हम उसके तत्वों को बदल (Modify), जोड़ (Add) या हटा (Delete) नहीं सकते।

  • टपल को छोटे कोष्ठक Parentheses ( ) में लिखा जाता है। जैसे: t = (10, 20, "Python")
  • बिना कोष्ठक के केवल कॉमा लगाकर मान लिखने पर भी पायथन उसे टपल मानता है (इसे Tuple Packing कहते हैं), जैसे: t = 10, 20, 30।
Common Mistake: Creating a Single Element Tuple

यदि आप एक तत्व का टपल बनाने के लिए केवल t = (50) लिखते हैं, तो पायथन इसे टपल नहीं बल्कि एक साधारण पूर्णांक (int) मानेगा! एकल तत्व (Singleton Tuple) बनाने के लिए तत्व के बाद कॉमा (,) लगाना अनिवार्य है: t = (50,)

2.1 Tuple Methods: index() and count()

चूँकि टपल Immutable (अपरिवर्तनीय) होता है, इसलिए इसमें append(), remove() या pop() जैसे मेथड्स नहीं होते। टपल में मुख्य रूप से दो ही इन-बिल्ट मेथड्स होते हैं:

  1. tuple.index(item): यह टपल में दिए गए तत्व के पहले स्थान (First Index) को लौटाता है। तत्व न मिलने पर ValueError देता है।
  2. tuple.count(item): यह बताता है कि दिया गया तत्व टपल में कितनी बार आया है। यदि तत्व मौजूद नहीं है, तो यह 0 लौटाता है।
# Creating Tuples and using index() and count() single_tuple = (100,) print("Type of single_tuple:", type(single_tuple)) # Output: <class 'tuple'> scores = (85, 90, 75, 90, 95, 90) print("Count of 90:", scores.count(90)) # Output: 3 print("First Index of 75:", scores.index(75)) # Output: 2 # Trying to modify a tuple raises TypeError: # scores[0] = 100 --> TypeError: 'tuple' object does not support item assignment

2.2 Usage of Tuples (Why use Tuples instead of Lists?)

जब हमारे पास लिस्ट है, तो हमें टपल की आवश्यकता क्यों पड़ती है? इसके प्रमुख कारण निम्नलिखित हैं:

  • 1. Faster Execution Speed: चूँकि टपल का आकार और डेटा निश्चित (Immutable) होता है, इसलिए यह लिस्ट की तुलना में कम मेमोरी घेरता है और तेज़ी से प्रोसेस होता है।
  • 2. Data Security (Write-Protected Data): जब हम चाहते हैं कि प्रोग्राम के चलते समय कोई भी गलती से हमारे महत्वपूर्ण डेटा (जैसे: आधार नंबर, जन्मतिथि, सप्ताह के दिन, भू-निर्देशांक) को बदल न सके, तब हम टपल का उपयोग करते हैं।
  • 3. Valid Dictionary Keys: डिक्शनरी में कुंजी (Key) केवल Immutable डेटा प्रकार की हो सकती है। लिस्ट को डिक्शनरी की Key नहीं बनाया जा सकता, लेकिन Tuple को डिक्शनरी की Key के रूप में उपयोग किया जा सकता है।
  • 4. Returning Multiple Values from Functions: जब कोई फंक्शन एक से अधिक मान एक साथ लौटाता है, तो वह उन्हें टपल के रूप में ही लौटाता है।

2.3 Use of Tuples as a Swap Function

C, C++ या Java जैसी भाषाओं में दो वेरिएबल्स के मान आपस में बदलने (Swapping) के लिए एक तीसरे अस्थायी वेरिएबल (temp) की आवश्यकता होती है। लेकिन पायथन में Tuple Packing और Unpacking की मदद से हम बिना किसी तीसरे वेरिएबल के, केवल एक लाइन a, b = b, a लिखकर दो वेरिएबल्स को स्वैप कर सकते हैं!

How a, b = b, a Works Internally using Tuple
Step 1: Right Side (b, a)
Creates a temporary Tuple (20, 10) (Tuple Packing)
Step 2: Left Side (a, b)
Unpacks 20 into a and 10 into b (Tuple Unpacking)
# Swapping two variables using Tuple Packing and Unpacking a = 10 b = 20 print("Before Swap -> a:", a, "b:", b) # Tuple assignment swaps values in a single line without a temp variable a, b = b, a print("After Swap -> a:", a, "b:", b) # Output: # Before Swap -> a: 10 b: 20 # After Swap -> a: 20 b: 10
Topic 3: Dictionaries

Dictionaries in Python

पायथन में Dictionary एक Mapping डेटा प्रकार है। जहाँ लिस्ट और टपल में डेटा को संख्यात्मक इंडेक्स (0, 1, 2...) द्वारा पहचाना जाता है, वहीं डिक्शनरी में डेटा को Key : Value (कुंजी : मान) के जोड़े (Pairs) के रूप में मंझले कोष्ठक Curly Brackets { } के अंदर स्टोर किया जाता है।

  • Unique & Immutable Keys: डिक्शनरी की प्रत्येक Key (कुंजी) अद्वितीय (Unique) होनी चाहिए (कोई भी दो Keys समान नहीं हो सकतीं) और Key हमेशा Immutable (जैसे int, str, tuple) होनी चाहिए।
  • Mutable Values: डिक्शनरी स्वयं Mutable होती है और इसके Values (मान) किसी भी डेटा प्रकार के हो सकते हैं और डुप्लीकेट भी हो सकते हैं।

3.1 Dictionary Methods: keys(), values(), and items() (Tuples)

डिक्शनरी से कुंजियों, मानों और टपल जोड़ों को प्राप्त करने के लिए तीन मुख्य मेथड्स का उपयोग किया जाता है:

Method Return Format Explanation in Hindi
1. dict.keys() dict_keys([k1, k2, ...]) यह डिक्शनरी में मौजूद सभी Keys (कुंजियों) की एक सूची (View object) लौटाता है।
2. dict.values() dict_values([v1, v2, ...]) यह डिक्शनरी में मौजूद सभी Values (मानों) की एक सूची लौटाता है।
3. dict.items() (Tuples) dict_items([(k1, v1), (k2, v2)]) यह डिक्शनरी के प्रत्येक Key:Value जोड़े को (key, value) Tuples की सूची के रूप में लौटाता है। लूप चलाने के लिए यह सबसे उपयोगी मेथड है।
# Creating a Dictionary and accessing keys, values, and tuple pairs student = {"roll_no": 101, "name": "Rohan", "marks": 92.5} # Adding / Updating a key-value pair student["grade"] = "A1" print("All Keys:", list(student.keys())) # Output: ['roll_no', 'name', 'marks', 'grade'] print("All Values:", list(student.values())) # Output: [101, 'Rohan', 92.5, 'A1'] print("All Items (List of Tuples):", list(student.items())) # Output: [('roll_no', 101), ('name', 'Rohan'), ('marks', 92.5), ('grade', 'A1')] # Traversing dictionary using tuple unpacking in items(): for key, val in student.items(): print(key, "->", val)

3.2 Nested Dictionaries

जब एक डिक्शनरी के अंदर किसी Key के मान (Value) के रूप में एक और डिक्शनरी स्टोर की जाती है, तो उसे Nested Dictionary कहा जाता है। इसका उपयोग जटिल और पदानुक्रमित (Hierarchical) डेटा—जैसे कई छात्रों या कर्मचारियों का पूरा रिकॉर्ड—स्टोर करने के लिए किया जाता है।

# Example of Nested Dictionary: Storing records of multiple students classroom = { "S101": {"name": "Aman", "age": 17, "marks": 88}, "S102": {"name": "Priya", "age": 16, "marks": 95} } # Accessing nested elements using multiple square brackets [outer_key][inner_key]: print("Name of S101:", classroom["S101"]["name"]) # Output: Aman print("Marks of S102:", classroom["S102"]["marks"]) # Output: 95 # Modifying a nested value: classroom["S101"]["marks"] = 91 print("Updated S101 Record:", classroom["S101"]) # Output: {'name': 'Aman', 'age': 17, 'marks': 91}

3.3 Dictionary Comprehension

जिस प्रकार List Comprehension से एक लाइन में लिस्ट बनाई जाती है, उसी प्रकार Dictionary Comprehension का उपयोग करके हम केवल एक ही लाइन के कोड में नई डिक्शनरी बना सकते हैं। इसका सिंटैक्स है:

new_dict = {key_expr : value_expr for item in iterable if condition}

# 1. Creating a dictionary of numbers and their cubes from 1 to 5: cubes = {x: x ** 3 for x in range(1, 6)} print("Cubes Dictionary:", cubes) # Output: {1: 1, 2: 8, 3: 27, 4: 64, 5: 125} # 2. Dictionary Comprehension with if condition (Only Even squares): even_squares = {x: x ** 2 for x in range(1, 9) if x % 2 == 0} print("Even Squares:", even_squares) # Output: {2: 4, 4: 16, 6: 36, 8: 64} # 3. Creating a dictionary from two lists using zip(): names = ["Rahul", "Sneha", "Karan"] scores = [85, 92, 78] result_dict = {k: v for k, v in zip(names, scores)} print("Student Scores:", result_dict) # Output: {'Rahul': 85, 'Sneha': 92, 'Karan': 78}
Topic 4: Strings

Strings in Python

पायथन में String अक्षरों, अंकों या विशेष चिह्नों (Characters / Unicode characters) का एक क्रमबद्ध अनुक्रम (Sequence) है। स्ट्रिंग एक Immutable (अपरिवर्तनीय) डेटा प्रकार है, अर्थात एक बार स्ट्रिंग बन जाने के बाद हम उसके किसी अक्षर को सीधे इंडेक्स द्वारा बदल नहीं सकते (जैसे s[0] = 'A' करने पर TypeError आता है)।

4.1 Single-line and Multi-line Strings

  • Single-line Strings: वे स्ट्रिंग्स जो एक ही लाइन में शुरू और समाप्त हो जाती हैं। इन्हें Single Quotes (' ') या Double Quotes (" ") के अंदर लिखा जाता है।
  • Multi-line Strings: जब हमें एक से अधिक लाइनों (Multiple Lines / Paragraphs) का टेक्स्ट स्टोर करना हो, तो हम Triple Quotes (''' ''' या """ """) का उपयोग करते हैं। इसमें नई लाइन (Enter) और स्पेस अपने आप सुरक्षित रहते हैं।
# 1. Single-line Strings str1 = 'Hello Python' str2 = "Welcome to NCERT Notes" # 2. Multi-line String using Triple Quotes multi_str = """Python is easy to learn. It supports multiple data structures. Strings are immutable in Python.""" print(multi_str)

4.2 String Formatter (.format() and f-strings)

स्ट्रिंग के बीच में वेरिएबल्स के मानों को डायनामिक रूप से फिट (Insert) करने की प्रक्रिया को String Formatting कहते हैं। पायथन में इसके लिए प्लेसहोल्डर { } के साथ .format() मेथड और आधुनिक f-string का उपयोग किया जाता है:

name = "Vikram" age = 18 percentage = 94.567 # Method 1: Default Positional .format() print("Hello {}, you are {} years old.".format(name, age)) # Method 2: Indexed and Keyword .format() print("Student {1} scored {0}% marks.".format(percentage, name)) print("City: {city}, Pin: {pin}".format(city="Indore", pin=452001)) # Method 3: Modern f-string (Formatted String Literal - Python 3.6+) print(f"{name} is {age} years old and scored {percentage:.2f}%.") # Output: Vikram is 18 years old and scored 94.57%.

Topic 5: Sets

Sets in Python

पायथन में Set अद्वितीय (Unique) तत्वों का एक अक्रमबद्ध (Unordered) और असूचीबद्ध (Unindexed) संग्रह है। यह गणित के समुच्चय सिद्धांत (Mathematical Set Theory) पर आधारित है। सेट के तत्वों को मंझले कोष्ठक Curly Brackets { } के अंदर कॉमा से अलग करके लिखा जाता है।

  • No Duplicate Elements: सेट कभी भी डुप्लीकेट मान स्टोर नहीं करता। यदि आप {10, 20, 10, 30} बनाते हैं, तो पायथन अपने आप डुप्लीकेट हटाकर उसे {10, 20, 30} कर देगा।
  • Unordered & Unindexed: सेट में तत्वों का कोई निश्चित क्रम या इंडेक्स नहीं होता, इसलिए आप my_set[0] लिखकर तत्व एक्सेस नहीं कर सकते।
  • Empty Set Rule: खाली मंझला कोष्ठक s = {} एक खाली Dictionary बनाता है, सेट नहीं! खाली सेट बनाने के लिए हमेशा s = set() का उपयोग किया जाता है।

5.1 Adding, Copying and Removing Elements (add, copy, remove, discard)

Method Syntax Explanation in Hindi
1. add() set.add(item) यह सेट में एक नया तत्व जोड़ता है। (यदि तत्व पहले से मौजूद है, तो कुछ नहीं बदलता)।
2. copy() set.copy() यह सेट की एक स्वतंत्र उथली कॉपी (Shallow Copy) बनाकर लौटाता है।
3. remove() set.remove(item) यह दिए गए तत्व को सेट से हटाता है। यदि तत्व सेट में मौजूद नहीं है, तो यह KeyError देता है!
4. discard() set.discard(item) यह भी दिए गए तत्व को सेट से हटाता है, लेकिन इसकी खासियत यह है कि यदि तत्व सेट में न मिले, तो यह कोई Error नहीं देता (प्रोग्राम सुरक्षित रूप से चलता रहता है)।
# Demonstration of add(), copy(), remove(), and discard() colors = {"Red", "Green", "Blue", "Red"} print("Unique Set:", colors) # Output: {'Red', 'Green', 'Blue'} colors.add("Yellow") backup_colors = colors.copy() colors.remove("Green") # Removes 'Green' colors.discard("Purple") # 'Purple' is not in set, but NO error is raised! # colors.remove("Purple") # Raises KeyError: 'Purple' print("Modified Set:", colors) print("Copied Set:", backup_colors)

5.2 Mathematical Set Operations

मान लीजिए हमारे पास दो सेट हैं: A = {1, 2, 3, 4} और B = {3, 4, 5, 6}। पायथन में इन पर निम्नलिखित गणितीय ऑपरेशन्स किए जा सकते हैं:

Operation Method & Operator Meaning in Hindi Result for A={1,2,3,4}, B={3,4,5,6}
1. Union (सम्मिलन) A.union(B)
या A | B		 दोनों सेटों के सभी तत्वों को मिलाकर एक नया सेट बनाता है (डुप्लीकेट केवल एक बार आते हैं)। {1, 2, 3, 4, 5, 6}
2. Intersection (सर्वनिष्ठ) A.intersection(B)
या A & B		 केवल वे तत्व लौटाता है जो दोनों सेटों में उभयनिष्ठ (Common) हैं। {3, 4}
3. Difference (अंतर) A.difference(B)
या A - B		 सेट A के वे तत्व जो सेट B में मौजूद नहीं हैं। A - B → {1, 2}
B - A → {5, 6}
4. Symmetric Difference A.symmetric_difference(B)
या A ^ B		 दोनों सेटों के वे सभी तत्व जो आपस में कॉमन (Common) नहीं हैं। अर्थात (A | B) - (A & B)। {1, 2, 5, 6}
5. Subset (उपसमुच्चय) X.issubset(A)
या X <= A		 यदि सेट X का प्रत्येक तत्व सेट A में मौजूद है, तो True लौटाता है। {1, 2}.issubset(A) → True
6. Superset (अधिसमुच्चय) A.issuperset(X)
या A >= X		 यदि सेट A के अंदर सेट X के सभी तत्व मौजूद हैं, तो True लौटाता है। A.issuperset({1, 2}) → True
# Complete Program for Mathematical Set Operations A = {1, 2, 3, 4} B = {3, 4, 5, 6} C = {1, 2} print("Union (A | B):", A.union(B)) # Output: {1, 2, 3, 4, 5, 6} print("Intersection (A & B):", A.intersection(B)) # Output: {3, 4} print("Difference (A - B):", A.difference(B)) # Output: {1, 2} print("Symmetric Difference (A ^ B):", A.symmetric_difference(B)) # Output: {1, 2, 5, 6} print("Is C a subset of A?:", C.issubset(A)) # Output: True print("Is A a superset of C?:", A.issuperset(C)) # Output: True
