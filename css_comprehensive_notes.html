Complete Guide to CSS (Cascading Style Sheets)

What is CSS & Why do we need it?

शुरुआत में, HTML को केवल डेटा (टेक्स्ट और इमेज) दिखाने के लिए बनाया गया था, डिज़ाइन करने के लिए नहीं। जब वेबसाइट्स को सुंदर बनाने की आवश्यकता हुई, तो HTML के अंदर डिज़ाइनिंग टैग्स (जैसे <font>, <color>) लिखने से कोड बहुत लंबा और जटिल हो गया। इस समस्या को सुलझाने के लिए W3C (World Wide Web Consortium) ने CSS का निर्माण किया।

CSS वह भाषा है जो यह तय करती है कि HTML एलिमेंट्स स्क्रीन पर कैसे दिखेंगे।

🏛️ Analogy:
HTML = मकान की ईंटें (Structure)
CSS = पेंट, टाइल्स और सजावट (Style)

Features of Style Sheet (CSS की विशेषताएं)

एक पेशेवर वेब डेवलपर के लिए CSS सीखना अनिवार्य है, क्योंकि इसके निम्नलिखित महत्वपूर्ण फायदे हैं:

  • Separation of Concerns (विभाजन): सबसे बड़ा फायदा यह है कि HTML (कंटेंट) और CSS (डिज़ाइन) अलग-अलग रहते हैं। इससे कोड पढ़ना और समझना बहुत आसान हो जाता है।
  • Ultimate Reusability (पुन: उपयोग): आप एक बार CSS कोड लिखते हैं और उसे वेबसाइट के हज़ारों पेजों पर लागू कर सकते हैं। बार-बार एक ही डिज़ाइन कोड नहीं लिखना पड़ता।
  • Easy Maintenance (आसान रखरखाव): यदि भविष्य में आपको पूरी वेबसाइट का थीम (Theme) कलर बदलना हो, तो आपको केवल एक .css फाइल में बदलाव करना होगा। पूरी साइट का डिज़ाइन अपने आप अपडेट हो जाएगा!
  • Faster Page Load (तेज़ स्पीड): जब यूज़र आपकी वेबसाइट खोलता है, तो ब्राउज़र CSS फाइल को एक बार डाउनलोड करके अपने पास (Cache) रख लेता है। इससे अगले पेजों को लोड होने में बहुत कम समय लगता है।
  • Responsive Design: CSS की मदद से हम वेबसाइट को मोबाइल, टैबलेट और लैपटॉप के स्क्रीन साइज के अनुसार अपने आप ढलने (Adjust) वाला बना सकते हैं।

Types of CSS (Style Placement)

CSS कोड को HTML के साथ जोड़ने (Placement) के 3 मुख्य तरीके होते हैं। आवश्यकता के अनुसार हम तय करते हैं कि कौन सा तरीका इस्तेमाल करना है:

1. Inline CSS (इनलाइन स्टाइल)

Definition: जब हम CSS को सीधे HTML के शुरुआती टैग (Opening Tag) के अंदर style एट्रिब्यूट का उपयोग करके लिखते हैं, तो उसे Inline CSS कहते हैं।

Pros: इसकी Priority (प्राथमिकता) सबसे ज्यादा होती है। यह त्वरित (quick) बदलावों के लिए अच्छा है।
Cons: इसे बड़े प्रोजेक्ट्स में उपयोग नहीं करना चाहिए क्योंकि यह कोड को बहुत गंदा (messy) कर देता है और हम इस डिज़ाइन को दोबारा (reuse) इस्तेमाल नहीं कर सकते।

<!-- Inline CSS Example --> <h1 style="color: white; background-color: tomato; text-align: center;"> This is an Inline Style Headline! </h1>

This is an Inline Style Headline!

2. Internal CSS (इंटरनल / Header स्टाइल)

Definition: जब हम पूरे एक HTML पेज का डिज़ाइन उसी पेज के <head> सेक्शन में <style> टैग के अंदर लिखते हैं, तो उसे Internal CSS कहते हैं।

Use Case: इसका उपयोग तब किया जाता है जब किसी एक विशिष्ट (specific) पेज का डिज़ाइन बाकी पूरी वेबसाइट से अलग रखना हो।

<!DOCTYPE html> <html> <head> <style> body { background-color: #f4f4f9; } .internal-box { border: 2px dashed blue; padding: 15px; font-size: 18px; color: darkblue; } </style> </head> <body> <div class="internal-box">Styled using Internal CSS!</div> </body> </html>
Styled using Internal CSS!

3. External CSS (एक्सटर्नल स्टाइल शीट)

Definition: यह सबसे बेहतरीन और प्रोफेशनल तरीका है। इसमें हम HTML फाइल और CSS फाइल को बिल्कुल अलग-अलग रखते हैं। हम एक नई फाइल बनाते हैं जिसे .css एक्सटेंशन के साथ सेव करते हैं (जैसे: style.css)। फिर इस फाइल को HTML के <head> भाग में <link> टैग का उपयोग करके जोड़ते हैं।

Ultimate Benefit: आप एक style.css फाइल को वेबसाइट के 500 पेजों से लिंक कर सकते हैं। एक जगह कोड बदलने पर पूरी वेबसाइट बदल जाएगी!

🏆 Pro Tip:
Always use External CSS for real-world projects to keep code clean and fast.
/* 📄 File 1: style.css (Only CSS code here) */ .btn-primary { background-color: green; color: white; padding: 10px 20px; border-radius: 8px; border: none; }
<!-- 📄 File 2: index.html --> <head> <link rel="stylesheet" href="style.css"> </head> <body> <button class="btn-primary">Submit Form</button> </body>

Working with Span & Div Tags

<div> और <span> दोनों का अपना कोई रूप या आकार नहीं होता है। इनका मुख्य काम HTML एलिमेंट्स को एक समूह (Group) में बांधना है ताकि हम उन पर CSS लगा सकें।

  • Div (<div> - Division): यह एक Block-level एलिमेंट है। ब्लॉक लेवल एलिमेंट्स हमेशा एक नई लाइन (New Line) से शुरू होते हैं और स्क्रीन की पूरी चौड़ाई (100% width) घेर लेते हैं। इसका उपयोग बड़े लेआउट्स (जैसे Header, Footer, Sidebar) बनाने के लिए किया जाता है।
  • Span (<span>): यह एक Inline एलिमेंट है। यह नई लाइन से शुरू नहीं होता है। यह स्क्रीन पर केवल उतनी ही जगह (width) घेरता है जितना इसके अंदर का टेक्स्ट होता है। इसका उपयोग पैराग्राफ के बीच में किसी खास शब्द को रंगने या हाईलाइट करने के लिए किया जाता है।

Defining Style with HTML Tags (Selectors)

CSS को यह बताने के लिए कि कौन से HTML एलिमेंट को स्टाइल करना है, हम Selectors का उपयोग करते हैं।

1. Element / Tag Selector

हम सीधे HTML टैग का नाम लिखते हैं। यह पेज पर मौजूद उन सभी टैग्स पर स्टाइल लागू कर देगा। (उदा: p { color: red; } पेज के सभी पैराग्राफ को लाल कर देगा)।

2. CSS Class Selector (.)

जब हम चाहते हैं कि अलग-अलग एलिमेंट्स पर एक जैसी स्टाइल लागू हो, तो हम Class बनाते हैं। CSS में इसे डॉट (.) से शुरू करते हैं। एक ही HTML पेज पर एक नाम की कई Classes हो सकती हैं।

3. CSS ID Selector (#)

ID का उपयोग किसी एक अद्वितीय (Unique) एलिमेंट को स्टाइल करने के लिए किया जाता है (जैसे मेन नेविगेशन बार)। इसे CSS में हैश (#) से दर्शाते हैं। (नियम: एक पेज पर एक नाम की केवल एक ही ID हो सकती है)।

🎯 Priority Fight:
ID 🥊 Class
ID Wins! ID is more powerful than Class.

CSS Colors (रंगों के प्रकार)

CSS में किसी भी एलिमेंट को रंग देने के लिए 3 बहुत लोकप्रिय तरीके (Formats) हैं:

  1. Color Name: सीधे रंग का नाम (जैसे: red, blue, crimson, teal)। ब्राउज़र 140 से अधिक स्टैंडर्ड नामों को सपोर्ट करता है।
  2. HEX Code (Hexadecimal): यह वेब डिज़ाइन का सबसे लोकप्रिय तरीका है। यह # से शुरू होता है और 6 अक्षरों/नंबरों का होता है (उदा: #FF0000 लाल रंग के लिए)।
  3. RGB Value: यह Red, Green, और Blue रंगों के मिश्रण से रंग बनाता है। इसकी वैल्यू 0 से 255 तक होती है (उदा: rgb(0, 255, 0) शुद्ध हरे रंग के लिए)।
<style> /* Targeting ID (#) */ #special-box { background-color: #333333; padding: 15px; } /* Targeting Class (.) */ .neon-text { color: rgb(0, 255, 255); font-weight: bold; } </style> <div id="special-box"> <span class="neon-text">Cyberpunk Style Text!</span> </div>

Style Properties (विस्तृत गुण)

एक सुंदर वेब पेज बनाने के लिए हमें फॉन्ट, टेक्स्ट और बैकग्राउंड को सही तरीके से कंट्रोल करना आना चाहिए।

1. Controlling Fonts (फ़ॉन्ट नियंत्रण)

Typography (अक्षरों की बनावट) डिज़ाइन का सबसे महत्वपूर्ण हिस्सा है:

  • font-family: यह फॉन्ट का चेहरा (Typeface) बदलता है। हमेशा एक से ज़्यादा नाम (Fallback) देने चाहिए। (उदा: 'Arial', sans-serif)।
  • font-size: यह टेक्स्ट का आकार बदलता है। इसके लिए हम px (पिक्सल्स), em (सापेक्ष आकार), या rem का उपयोग करते हैं।
  • font-style: टेक्स्ट को तिरछा (italic) करने के लिए।
  • font-weight: टेक्स्ट की मोटाई तय करता है (normal, bold, 100 से 900 तक)।

2. Text Format (टेक्स्ट फ़ॉर्मैटिंग)

टेक्स्ट को सही जगह और सही रूप में दिखाने के लिए इन प्रॉपर्टीज़ का उपयोग होता है:

  • text-align: टेक्स्ट को संरेखित (align) करता है (left, right, center, justify)।
  • text-decoration: लिंक्स के नीचे की लाइन हटाने (none) या टेक्स्ट को काटने (line-through) या नीचे लाइन खींचने (underline) के लिए।
  • text-transform: अक्षरों को कैपिटल (uppercase) या स्माल (lowercase) करने के लिए।
  • line-height: दो लाइनों (पंक्तियों) के बीच की दूरी (Gap) तय करने के लिए।

3. Styling Background (बैकग्राउंड डिज़ाइन)

  • background-color: एलिमेंट के पीछे एक ठोस रंग (Solid Color) भरता है।
  • background-image: किसी फोल्डर या URL से इमेज लाकर पीछे लगाता है (उदा: url('image.jpg'))।
  • background-repeat: यह रोकता है कि छोटी इमेज बार-बार रिपीट न हो (no-repeat)।
  • background-size: इमेज को पूरे डिब्बे में फिट करने के लिए cover या contain का उपयोग होता है।
<style> .hero-text { font-family: 'Verdana', sans-serif; font-size: 28px; font-weight: 900; text-transform: uppercase; text-align: center; text-decoration: underline dashed red; background-color: #2c3e50; color: #ecf0f1; padding: 20px; } </style> <p class="hero-text">Styling is Awesome!</p>

Working with Lists and Tables

CSS for Lists (सूचियों को डिज़ाइन करना)

HTML में Unordered (<ul>) और Ordered (<ol>) लिस्ट्स होती हैं। CSS की मदद से हम उनके डिफ़ॉल्ट बुलेट्स और नंबर्स को बदल सकते हैं या पूरी तरह हटा सकते हैं (जैसे नेविगेशन मेन्यू बनाने के लिए)।

  • list-style-type: बुलेट्स को circle, square, upper-roman, decimal में बदलता है। यदि मेन्यू बार बनाना हो तो इसे none कर देते हैं।
  • list-style-image: बोरिंग बुलेट्स की जगह आप अपनी खुद की छोटी सी इमेज (Icon) लगा सकते हैं (उदा: url('arrow.png'))।

CSS for Tables (तालिका डिज़ाइन)

बिना CSS के HTML टेबल्स बहुत बदसूरत दिखते हैं। हम उन्हें आकर्षक और पढ़ने में आसान बना सकते हैं:

  • border: 1px solid black; टेबल और सेल्स के चारों ओर लाइन बनाता है।
  • border-collapse: collapse; यह बहुत महत्वपूर्ण है! यह टेबल की दोहरी (Double) लाइनों को मिलाकर एक सिंगल, साफ लाइन में बदल देता है।
  • padding: सेल के अंदर के डेटा (टेक्स्ट) को सांस लेने की जगह देता है (स्पेस बनाता है)।

Working with Block Elements & Objects (Box Model)

CSS का सबसे महत्वपूर्ण कांसेप्ट है "Box Model"। वेब पेज पर मौजूद हर एक एलिमेंट (चाहे वह पैराग्राफ हो, इमेज हो या बटन) को एक आयताकार "बॉक्स" (Rectangular Box) के रूप में माना जाता है।

📦 Box Anatomy:
1. Content (अंदर का माल)
2. Padding (कुशन)
3. Border (दीवार)
4. Margin (बाहरी दूरी)

जब हम इन बॉक्सेस/ऑब्जेक्ट्स को कंट्रोल करते हैं, तो हम 4 प्रॉपर्टीज़ का उपयोग करते हैं:

  1. Content (width/height): यह बॉक्स का मुख्य भाग है जहाँ हमारा टेक्स्ट या इमेज (Object) रहता है।
  2. Padding (अंदर की दूरी): यह कंटेंट और बॉर्डर (दीवार) के बीच की खाली जगह है। यह बॉक्स के अंदर स्पेस बनाता है।
  3. Border (सीमा/दीवार): यह पैडिंग और कंटेंट के चारों ओर खींची गई लाइन होती है।
  4. Margin (बाहर की दूरी): यह बॉक्स के सबसे बाहर की खाली जगह है। इसका काम दो अलग-अलग बॉक्सेस (एलिमेंट्स) को आपस में टकराने से रोकना और उनके बीच दूरी (Gap) बनाना है।
.my-box-model { width: 300px; /* Content Size */ padding: 20px; /* Space INSIDE border */ border: 5px solid red; /* The Wall */ margin: 30px; /* Space OUTSIDE border */ }
