Topic 1

Introduction to Python, Interpreter and IDLE

Python एक उच्च-स्तरीय (High-level), इंटरप्रिटेड (Interpreted), और ऑब्जेक्ट-ओरिएंटेड प्रोग्रामिंग भाषा है। इसका निर्माण Guido van Rossum द्वारा सन् 1991 में किया गया था। पायथन की सबसे बड़ी खासियत इसका सरल सिंटैक्स (Syntax) है, जो सामान्य अंग्रेजी भाषा के बहुत करीब है।

1.1 Python Interpreter

कंप्यूटर केवल मशीनी भाषा (Machine Language यानी 0 और 1 बाइनरी) समझता है, जबकि हम प्रोग्राम्स को हाई-लेवल भाषा (जैसे Python) में लिखते हैं। इसलिए हमारे लिखे गए कोड (Source Code) को मशीनी भाषा में बदलने के लिए एक अनुवादक (Translator) की आवश्यकता होती है।

पायथन में इस अनुवाद के लिए Interpreter (इंटरप्रेटर) का उपयोग किया जाता है। इंटरप्रेटर का मुख्य कार्य प्रोग्राम के निर्देशों को एक-एक लाइन (Line-by-Line) करके पढ़ना, उसका विश्लेषण करना और उसे तुरंत निष्पादित (Execute) करना है।

How Python Interpreter Works

Compiler (Internal)
Bytecode (.pyc) में बदलता है

Did You Know? (Compiler vs Interpreter)

Compiler (जैसे C, C++ में): यह पूरे प्रोग्राम को एक ही बार में स्कैन करके मशीनी भाषा में बदल देता है। यदि कोड में गलतियाँ हों, तो सभी गलतियाँ एक साथ अंत में दिखाता है।
Interpreter (जैसे Python में): यह कोड को एक-एक लाइन (Line-by-Line) करके अनुवाद और रन करता है। जैसे ही किसी लाइन में कोई गलती (Error) मिलती है, यह वहीं रुक जाता है और आगे की लाइनें तब तक नहीं चलाता जब तक वह गलती ठीक न कर दी जाए।

1.2 Python IDLE

जब हम अपने कंप्यूटर में मानक पायथन (Standard Python) इंस्टॉल करते हैं, तो उसके साथ हमें कोड लिखने और चलाने के लिए एक विशेष सॉफ्टवेयर मुफ़्त मिलता है, जिसे IDLE कहा जाता है।

  • IDLE का पूरा नाम: Integrated Development and Learning Environment है।
  • इसमें कोड लिखने के लिए एक एडिटर (Syntax Highlighting और Auto-completion के साथ), कोड चलाने के लिए Python Shell, और गलतियाँ ढूँढने के लिए एक Debugger शामिल होता है।

Modes of Working in Python IDLE:

NCERT के अनुसार, पायथन इंटरप्रेटर के साथ काम करने के दो मुख्य मोड होते हैं:

Basis 1. Interactive Mode 2. Script Mode
Prompt इसमें >>> (Chevron prompt) दिखाई देता है। यह एक खाली नोटपैड फाइल की तरह (File Editor) होता है।
Execution इसमें आप एक कमांड टाइप करते हैं और Enter दबाते ही तुरंत परिणाम (Output) मिल जाता है। इसमें हम एक साथ कई लाइनों का पूरा प्रोग्राम लिखते हैं, उसे सेव करते हैं और फिर एक साथ रन करते हैं।
Saving Code इसमें लिखा गया कोड भविष्य के लिए सेव (Save) नहीं होता। विंडो बंद करते ही कोड मिट जाता है। इसमें कोड को .py एक्सटेंशन के साथ हार्ड डिस्क पर सेव किया जाता है।
Primary Use छोटे एक्सप्रेशन टेस्ट करने या किसी कमांड को जल्दी से सीखने के लिए। बड़े प्रोग्राम्स, प्रोजेक्ट्स और असाइनमेंट्स बनाने के लिए।

Topic 2

Creating and Executing .py Scripts

जब हमें एक से अधिक लाइनों का कोड लिखना होता है और उसे भविष्य के उपयोग के लिए सुरक्षित रखना होता है, तो हम Script Mode का उपयोग करते हैं। पायथन की सोर्स कोड फाइल को स्क्रिप्ट (Script) कहा जाता है और इसका फाइल एक्सटेंशन हमेशा .py होता है।

2.1 Step-by-Step Process in IDLE:

  1. Step 1 (Open IDLE): सबसे पहले अपने कंप्यूटर में Start Menu से Python IDLE खोलें। आपके सामने Interactive Shell विंडो खुलेगी।
  2. Step 2 (Create New File): ऊपर मेन्यू बार में File → New File पर क्लिक करें (या शॉर्टकट की Ctrl + N दबाएँ)। अब एक नई खाली एडिटर विंडो खुल जाएगी।
  3. Step 3 (Write Code): इस नई विंडो में अपना पायथन प्रोग्राम लिखें। उदाहरण के लिए:
    # File Name: myfirstprog.py name = "Rohan" print("Welcome to Python,", name) print("Sum of 15 and 25 is:", 15 + 25)
  4. Step 4 (Save File): अब File → Save पर क्लिक करें (या Ctrl + S दबाएँ)। फाइल का नाम लिखें और अंत में .py लगाएँ (जैसे: myfirstprog.py)।
  5. Step 5 (Run / Execute Module): एडिटर विंडो के मेन्यू में Run → Run Module पर क्लिक करें या सीधे कीबोर्ड से F5 बटन दबाएँ।
  6. Step 6 (View Output): आपका प्रोग्राम निष्पादित होगा और उसका आउटपुट मुख्य Python Shell (Interactive Window) में दिखाई देगा।

2.2 Executing .py Scripts via Command Prompt (CMD / Terminal)

आप बिना IDLE खोले सीधे अपने ऑपरेटिंग सिस्टम के टर्मिनल या कमांड प्रॉम्प्ट (CMD) से भी पायथन स्क्रिप्ट चला सकते हैं:

# 1. Navigate to the folder where your file is saved: C:\Users\Student> cd Desktop # 2. Type python followed by the script name and press Enter: C:\Users\Student\Desktop> python myfirstprog.py # Output: Welcome to Python, Rohan Sum of 15 and 25 is: 40
Topic 3

Dynamically Typed and Strongly Typed Features

परीक्षा (Exams) और इंटरव्यू के दृष्टिकोण से यह सबसे महत्वपूर्ण विषय है। पायथन की टाइप प्रणाली (Type System) में दो प्रमुख विशेषताएँ होती हैं: यह Dynamically Typed भी है और Strongly Typed भी। आइए दोनों को विस्तार से समझते हैं:

3.1 Dynamically Typed Feature

C, C++, या Java जैसी भाषाओं (Statically Typed Languages) में किसी भी वेरिएबल का उपयोग करने से पहले उसका डेटा प्रकार (Data Type) घोषित करना अनिवार्य होता है (जैसे int x = 10;), और बाद में आप x में कोई स्ट्रिंग या दशमलव संख्या नहीं रख सकते।

परंतु Python एक Dynamically Typed भाषा है। इसका अर्थ है:

  • पायथन में वेरिएबल बनाते समय उसका डेटा प्रकार (int, float, str आदि) लिखने की आवश्यकता नहीं होती।
  • वेरिएबल का डेटा प्रकार प्रोग्राम के चलते समय (Run-time पर) उसमें डाली गई वैल्यू के आधार पर अपने आप तय हो जाता है।
  • एक ही वेरिएबल अलग-अलग समय पर अलग-अलग प्रकार के डेटा को स्टोर कर सकता है।
x = 100 # Here x is automatically assigned as Integer (int) print(type(x)) # Output: <class 'int'> x = 99.75 # Now the same x becomes a Float print(type(x)) # Output: <class 'float'> x = "NCERT" # Now the same x becomes a String (str)! print(type(x)) # Output: <class 'str'>

3.2 Strongly Typed Feature

कई छात्र यह गलती करते हैं कि चूँकि पायथन Dynamically Typed है, इसलिए यह Weakly Typed (कमजोर टाइपिंग वाली) भाषा होगी। यह गलत है! पायथन एक Strongly Typed भाषा है।

Strongly Typed का अर्थ है: पायथन में हर ऑब्जेक्ट का एक निश्चित प्रकार (Type) होता है, और पायथन दो असंगत डेटा प्रकारों (Incompatible Data Types) के बीच बिना स्पष्ट निर्देश के अपने आप (Implicitly) गलत बदलाव या ऑपरेशन की अनुमति नहीं देता है।

Why Python is Strongly Typed (Example):

यदि आप एक संख्या (int) और एक शब्द (str) को आपस में जोड़ने की कोशिश करेंगे, तो पायथन अपने आप संख्या को टेक्स्ट में नहीं बदलेगा, बल्कि तुरंत TypeError दे देगा। (जबकि JavaScript जैसी Weakly Typed भाषा में "5" + 10 का उत्तर "510" आ जाता है)।

a = 10 # Integer b = "20" # String # Wrong way (Raises TypeError because int and str cannot be added directly): # print(a + b) --> TypeError: unsupported operand type(s) for +: 'int' and 'str' # Right way (Using Explicit Type Conversion): print(a + int(b)) # Output: 30
Topic 4

Variables, Expressions, Statements and Flow of Execution

4.1 Variables

प्रोग्रामिंग में, Variable कंप्यूटर की मेमोरी (RAM) में स्थित किसी डेटा या मान (Value) को दिया गया एक नाम (Label या Reference) होता है। पायथन में वेरिएबल्स किसी डिब्बे (Container) की तरह काम नहीं करते, बल्कि वे एक ऑब्जेक्ट की ओर इशारा करने वाले नाम (Name Tag) की तरह काम करते हैं।

  • पायथन में वेरिएबल असाइनमेंट ऑपरेटर (=) की मदद से बनाया जाता है। जैसे: marks = 95
  • इसमें बाईं तरफ (Left side) लिखे वेरिएबल नाम को L-value और दाईं तरफ (Right side) लिखी गई वैल्यू को R-value कहते हैं।
  • मेमोरी एड्रेस जानने के लिए id() फंक्शन का उपयोग किया जाता है।

Rules for Naming Identifiers / Variables:

  1. वेरिएबल का नाम केवल अक्षरों (A-Z, a-z), अंकों (0-9), या अंडरस्कोर (_) से मिलकर बन सकता है।
  2. नाम की शुरुआत कभी भी किसी अंक (Digit) से नहीं हो सकती (जैसे 1num गलत है, लेकिन num1 सही है)।
  3. नाम के बीच में कोई खाली जगह (Space) या विशेष चिह्न (@, $, %, - आदि) नहीं हो सकता।
  4. पायथन के आरक्षित शब्दों (Keywords जैसे if, else, for, while, True, None) का उपयोग वेरिएबल नाम के रूप में नहीं किया जा सकता।
  5. पायथन Case-Sensitive है, अर्थात age, Age, और AGE तीनों अलग-अलग वेरिएबल माने जाएंगे।

4.2 Expressions vs Statements

NCERT परीक्षाओं में अक्सर Expression और Statement के बीच अंतर पूछा जाता है:

Basis Expression Statement
Definition मूल्यों (Values), वेरिएबल्स और ऑपरेटर्स का एक ऐसा वैध संयोजन जिसे हल (Evaluate) करने पर कोई एक मान (Single Value) प्राप्त होता है। कोड की एक पूर्ण निर्देश इकाई (Complete Instruction) जिसे पायथन इंटरप्रेटर निष्पादित (Execute) कर सकता है। यह कोई क्रिया (Action) करता है।
Result यह हमेशा कोई न कोई परिणाम (Value) लौटाता है। यह आवश्यक रूप से कोई वैल्यू नहीं लौटाता, बल्कि काम करता है (जैसे प्रिंट करना, लूप चलाना)।
Examples 15 + 20, x * y - 5, a > b x = 10 (Assignment Statement)
print(x), if x > 5:

4.3 Flow of Execution

किसी प्रोग्राम के अंदर लिखे गए स्टेटमेंट्स किस क्रम (Order) में एक के बाद एक चलते हैं, उसे Flow of Execution कहा जाता है। इंटरप्रेटर हमेशा प्रोग्राम की पहली लाइन (Top) से पढ़ना शुरू करता है। निष्पादन का प्रवाह तीन प्रकार का होता है:

1. Sequential Flow

डिफ़ॉल्ट रूप से कोड ऊपर से नीचे (Top-to-Bottom) एक के बाद एक सीधी रेखा में चलता है।

Stmt 1 → Stmt 2 → Stmt 3
2. Conditional / Selection Flow

इसमें किसी शर्त (if-else) के आधार पर तय होता है कि कौन सा कोड ब्लॉक चलेगा और कौन सा छूटेगा।

Condition ? True Path : False Path
3. Iterative / Repetitive Flow

इसमें एक ही कोड ब्लॉक को तब तक बार-बार दोहराया जाता है जब तक शर्त पूरी रहती है (for, while)।

Loop ↺ Repeat until False
Topic 5

Basic Data Types in Python

डेटा प्रकार (Data Type) यह निर्धारित करता है कि किसी वेरिएबल में किस प्रकार का मान स्टोर किया गया है और उस पर कौन-कौन से ऑपरेशन्स किए जा सकते हैं। किसी भी मान का डेटा प्रकार जांचने के लिए type() फंक्शन का प्रयोग किया जाता है।

Category Data Type Description Examples
1. Numbers int (Integer) धनात्मक या ऋणात्मक पूर्ण संख्याएँ (बिना दशमलव के)। 25, -104, 0
float (Floating Point) दशमलव (Decimal) वाली वास्तविक संख्याएँ या घातांक रूप। 3.14, -0.05, 2.5e3
complex $a + bj$ के रूप की संख्याएँ, जहाँ $a$ वास्तविक (real) और $b$ काल्पनिक (imaginary) भाग है। 3 + 4j, 2 - 5j
2. Boolean bool यह तार्किक सत्यता (Truth Value) को दर्शाता है। इसके केवल दो ही मान हो सकते हैं (int का उप-प्रकार)। True (1), False (0)
3. Sequences str (String) अक्षरों का समूह जो सिंगल (' '), डबल (" ") या ट्रिपल कोट्स में बंद होता है। (Immutable) "Python", '123'
list बड़े कोष्ठक [ ] में बंद विभिन्न डेटा आइटम्स की क्रमबद्ध सूची। इसे बदला जा सकता है (Mutable)। [10, "Ram", 85.5]
tuple छोटे कोष्ठक ( ) में बंद क्रमबद्ध सूची। एक बार बनने के बाद इसे बदला नहीं जा सकता (Immutable)। (10, 20, 30)
4. Mapping dict (Dictionary) मंझले कोष्ठक { } में Key : Value (कुंजी:मान) के जोड़े में डेटा स्टोर करता है। (Mutable) {"name": "Raj", "age": 17}
5. None NoneType यह एक विशेष डेटा प्रकार है जो 'कुछ नहीं' (Absence of a value / खालीपन) को दर्शाता है। x = None
Topic 6

Operators in Python

Operators (ऑपरेटर्स) वे विशेष प्रतीक या शब्द होते हैं जो वेरिएबल्स और मानों (जिन्हें Operands कहा जाता है) पर गणितीय या तार्किक गणनाएँ (Computations) करते हैं।

6.1 Arithmetic Operators

मान लीजिए a = 15 और b = 4 है:

Operator Name Description Example (a=15, b=4)
+ Addition दो संख्याओं को जोड़ता है (या दो स्ट्रिंग्स को आपस में जोड़ता है)। a + b → 19
- Subtraction पहली संख्या में से दूसरी संख्या घटाता है। a - b → 11
* Multiplication दो संख्याओं का गुणा करता है। a * b → 60
/ Division भाग देता है और परिणाम हमेशा Float (दशमलव) में देता है। a / b → 3.75
10 / 2 → 5.0
// Floor Division भाग देने के बाद दशमलव के बाद का हिस्सा हटाकर केवल पूर्णांक (Floor value) देता है। a // b → 3
-15 // 4 → -4
% Modulus भाग देने के बाद बचने वाला शेषफल (Remainder) देता है। a % b → 3
** Exponentiation घातांक (Power) की गणना करता है ($a^b$)। 2 ** 3 → 8 ($2^3$)

6.2 Relational / Comparison Operators

ये दो मानों की तुलना करते हैं और परिणाम हमेशा Boolean (True या False) में देते हैं:

  • == (Equal to): जैसे 5 == 5 → True
  • != (Not equal to): जैसे 5 != 3 → True
  • > (Greater than), < (Less than), >= (Greater than or equal to), <= (Less than or equal to)।

6.3 Assignment Operators

= का उपयोग मान असाइन करने के लिए होता है। इसके अलावा शॉर्टहैंड ऑपरेटर्स होते हैं: +=, -=, *=, /=, //=, %=, **=।
उदाहरण: x += 5 का बिल्कुल वही अर्थ है जो x = x + 5 का है।

6.4 Identity and Membership Operators

  • Identity Operators (is, is not): यह जांचते हैं कि क्या दो वेरिएबल्स मेमोरी के एक ही ऑब्जेक्ट की ओर इशारा कर रहे हैं (अर्थात क्या दोनों का id() समान है)।
  • Membership Operators (in, not in): यह जांचते हैं कि कोई मान किसी अनुक्रम (String, List, Tuple आदि) में मौजूद है या नहीं।
Exam Tip: Operator Precedence

जब एक ही एक्सप्रेशन में कई ऑपरेटर होते हैं, तो पायथन PEMDAS नियम का पालन करता है:
1. () Parentheses (कोष्ठक - सबसे उच्च प्राथमिकता)
2. ** Exponentiation (घातांक - यह Right-to-Left हल होता है! जैसे 2 ** 3 ** 2 = $2^{(3^2)} = 2^9 = 512$)
3. *, /, //, % (गुणा और भाग - Left-to-Right)
4. +, - (जोड़ और घटाव)
5. Relational (==, !=, >, <) → 6. not → 7. and → 8. or (सबसे कम प्राथमिकता)।

Topic 7

Input and Output Statements

7.1 Taking Input: The input() Function

प्रोग्राम के रन होते समय उपयोगकर्ता (User) से कीबोर्ड के माध्यम से डेटा लेने के लिए input() फंक्शन का उपयोग किया जाता है।

Golden Rule of input():

input() फंक्शन उपयोगकर्ता से जो कुछ भी लेता है, उसे हमेशा String (str) के रूप में ही लौटाता है—भले ही यूज़र ने कोई संख्या क्यों न टाइप की हो! इसलिए गणितीय गणना करने के लिए हमें int() या float() का उपयोग करके उसे बदलना (Typecast करना) पड़ता है।

# Taking String input: name = input("Enter your name: ") # Taking Numeric (Integer & Float) input: age = int(input("Enter your age: ")) price = float(input("Enter item price: ")) print("Hello", name, "next year you will be", age + 1, "years old.")

7.2 Displaying Output: The print() Function

स्क्रीन (Console) पर डेटा या परिणाम प्रदर्शित करने के लिए print() फंक्शन का उपयोग किया जाता है। इसमें दो अत्यंत महत्वपूर्ण वैकल्पिक पैरामीटर्स (Parameters) होते हैं:

  • 1. sep (Separator): जब हम print() में कॉमा (,) लगाकर एक से अधिक मान देते हैं, तो डिफ़ॉल्ट रूप से उनके बीच एक स्पेस (' ') छपता है। हम sep की मदद से स्पेस की जगह कोई भी चिह्न लगा सकते हैं।
  • 2. end: डिफ़ॉल्ट रूप से हर print() स्टेटमेंट के अंत में एक नई लाइन ('\n') जुड़ जाती है। यदि हम चाहते हैं कि अगला प्रिंट स्टेटमेंट भी उसी लाइन में छपे, तो हम end=" " का उपयोग करते हैं।
# Example of sep and end parameters: print("25", "12", "2026", sep="-") # Output: 25-12-2026 print("Hello", end=" ") print("World!") # Output: Hello World! (Printed on the same line)
Topic 8

Conditionals: Boolean, if, else, if-elif-else & Nested if

8.1 Boolean Values and Logical Operators

कंडीशनल स्टेटमेंट्स पूरी तरह से Boolean एक्सप्रेशन पर काम करते हैं। एक बूलियन एक्सप्रेशन वह होता है जिसका परिणाम या तो सत्य (True) होता है या असत्य (False)।

  • Truthy और Falsy मान: पायथन में False, शून्य (0, 0.0), खाली स्ट्रिंग (""), खाली लिस्ट ([]), और None को False (Falsy) माना जाता है। इनके अलावा अन्य सभी गैर-शून्य संख्याओं और मानों को True (Truthy) माना जाता है।
  • Boolean / Logical Operators:
    • and : यह तभी True देता है जब दोनों शर्तें सत्य हों।
    • or : यह तब True देता है जब दोनों में से कम से कम एक शर्त सत्य हो।
    • not : यह परिणाम को उल्टा कर देता है (True को False और False को True)।
Importance of Indentation

C++ या Java में कोड ब्लॉक बनाने के लिए घुंघराले कोष्ठक { } का उपयोग होता है, लेकिन पायथन में कोष्ठक के बजाय Indentation (लाइन की शुरुआत में छोड़ा गया खाली स्थान - आमतौर पर 4 Spaces या 1 Tab) का उपयोग किया जाता है। समान दूरी पर लिखे गए सभी स्टेटमेंट्स एक ही ब्लॉक का हिस्सा माने जाते हैं।

8.2 Conditional (if) Statement

यह सबसे सरल निर्णय लेने वाला स्टेटमेंट है। यदि दी गई शर्त (Condition) True होती है, तभी if के अंदर का ब्लॉक चलता है। यदि शर्त False है, तो वह ब्लॉक छोड़ दिया जाता है।

age = 20 if age >= 18: print("You are eligible to vote.") # 4 spaces indentation

8.3 Alternative Execution (if - else) Statement

जब हमारे पास दो विकल्प हों—यदि शर्त True हो तो पहला काम हो, और यदि शर्त False हो तो दूसरा (वैकल्पिक) काम हो, तब हम if-else का उपयोग करते हैं। दोनों में से कोई एक ब्लॉक का चलना तय होता है।

num = int(input("Enter a number: ")) if num % 2 == 0: print(num, "is an Even number.") else: print(num, "is an Odd number.")

8.4 Chained Conditionals (if - elif - else)

जब हमारे पास दो से अधिक संभावनाएँ (Multiple Conditions) होती हैं, तो हम if-elif-else श्रृंखला का उपयोग करते हैं। यहाँ elif का अर्थ "else if" होता है।

  • पायथन ऊपर से नीचे की ओर शर्तों को जांचता है।
  • जैसे ही कोई एक शर्त True मिल जाती है, उसका ब्लॉक चल जाता है और बाकी नीचे के सभी elif और else को छोड़ दिया जाता है।
  • यदि ऊपर की कोई भी शर्त सत्य नहीं होती, तो अंत में else ब्लॉक चलता है।
# Grading System using Chained Conditional (if-elif-else): marks = 82 if marks >= 90: print("Grade: A+ (Outstanding)") elif marks >= 75: print("Grade: A (Distinction)") elif marks >= 60: print("Grade: B (First Division)") elif marks >= 33: print("Grade: C (Pass)") else: print("Grade: F (Fail - Needs Improvement)")

>>> marks = 82 Grade: A (Distinction)

8.5 Nested if Statements

जब एक if या else स्टेटमेंट के अंदर दूसरा if, if-else या if-elif-else स्टेटमेंट लिखा जाता है, तो इसे Nested if Statement कहा जाता है। "Nesting" का अर्थ होता है—एक के अंदर दूसरा।

  • उपयोग कब करें? जब किसी दूसरी शर्त (Inner Condition) की जांच केवल तभी करनी हो जब पहली मुख्य शर्त (Outer Condition) सत्य (True) साबित हो जाए।
  • Indentation का नियम: बाहरी if (Outer if) के लिए 4 स्पेस और भीतरी if (Inner if) के लिए 8 स्पेस (यानी 2 Tabs) का इंडेंटेशन दिया जाता है।
Working of Nested if Statement
Outer if Condition?
True
Inner if Condition?
Inner Block Executes

Syntax of Nested if:

if condition_1: # Outer if condition # Executes if condition_1 is True if condition_2: # Inner (Nested) if condition # Executes when both condition_1 and condition_2 are True statement_A else: # Executes when condition_1 is True, but condition_2 is False statement_B else: # Executes when outer condition_1 is False statement_C

Example 1: Checking Positive Even / Odd Number using Nested if

नीचे दिए गए प्रोग्राम में पहले बाहरी if यह जांचता है कि संख्या धनात्मक (Positive) है या नहीं। यदि संख्या 0 या धनात्मक है, तभी भीतरी if-else यह जांचता है कि वह शून्य (Zero) है या धनात्मक सम/विषम संख्या है:

num = 24 if num >= 0: # Outer if if num == 0: # Inner if-elif-else print("The number is Zero.") elif num % 2 == 0: print(num, "is a Positive Even number.") else: print(num, "is a Positive Odd number.") else: # Outer else print(num, "is a Negative number.") # Output: 24 is a Positive Even number.

Example 2: Finding Largest of Three Numbers using Nested if

a = 45 b = 78 c = 62 if a >= b: if a >= c: print("Largest number is:", a) else: print("Largest number is:", c) else: if b >= c: print("Largest number is:", b) else: print("Largest number is:", c) # Output: Largest number is: 78
Topic 9

Iteration (Looping): while, for, range(), 'in' and 'not in'

निर्देशों के किसी समूह को किसी शर्त के पूरा होने तक बार-बार दोहराने की प्रक्रिया को Iteration (पुनरावृत्ति या लूपिंग) कहते हैं। पायथन में दो मुख्य लूप होते हैं: while लूप और for लूप।

9.1 The while Loop (Entry-Controlled Loop)

while लूप तब तक कोड को दोहराता रहता है जब तक उसकी शर्त (Test Condition) True रहती है। जैसे ही शर्त False होती है, लूप समाप्त हो जाता है। एक सही while लूप के 3 मुख्य भाग होते हैं:

  1. Initialization: लूप शुरू होने से पहले कंट्रोल वेरिएबल को शुरुआती मान देना।
  2. Test Condition: while के साथ लिखी जाने वाली बूलियन शर्त।
  3. Updation: लूप के अंदर वेरिएबल का मान बढ़ाना या घटाना। (यदि आप Updation भूल जाते हैं, तो लूप कभी खत्म नहीं होगा जिसे Infinite Loop कहते हैं!)
# Printing numbers from 1 to 5 using while loop: count = 1 # 1. Initialization while count <= 5: # 2. Condition print("Number:", count) count = count + 1 # 3. Updation print("Loop finished!")

9.2 The for Loop and Sequence Traversal (in & not in Operators)

पायथन का for लूप किसी अनुक्रम (Sequence जैसे String, List, Tuple) या range() के प्रत्येक तत्व (Item) पर एक-एक करके जाने के लिए बनाया गया है। किसी अनुक्रम के प्रत्येक तत्व को क्रम से एक्सेस करने की प्रक्रिया को Traversal (ट्रैवर्सल) कहते हैं।

  • in ऑपरेटर: यह अनुक्रम में से एक-एक मान निकालकर लूप वेरिएबल को देता है, और बूलियन शर्त में यह जांचता है कि कोई तत्व अनुक्रम में मौजूद है या नहीं।
  • not in ऑपरेटर: यह ठीक उल्टा काम करता है; यदि तत्व अनुक्रम में मौजूद नहीं है तो यह True लौटाता है।
# 1. String Traversal using 'for' and 'in': word = "PYTHON" for ch in word: print(ch, end=" - ") # Output: P - Y - T - H - O - N - # 2. List Traversal & 'not in' operator check: fruits = ["Apple", "Mango", "Banana"] if "Orange" not in fruits: print("\nOrange is not present in the list.")

9.3 Implementing for Loop through range() Function

range() पायथन का एक इन-बिल्ट फंक्शन है जो संख्याओं का एक अनुक्रम (Sequence of integers) उत्पन्न करता है। इसका सिंटैक्स है:

range(start, stop, step)

  • start (Optional): अनुक्रम कहाँ से शुरू होगा (डिफ़ॉल्ट मान 0 होता है)।
  • stop (Required): अनुक्रम कहाँ रुकेगा। ध्यान रहे: range() हमेशा stop से एक कदम पहले (stop - 1) पर रुक जाता है! यानी stop वाली संख्या खुद शामिल नहीं होती।
  • step (Optional): दो संख्याओं के बीच का अंतर (डिफ़ॉल्ट मान +1 होता है)। उल्टी गिनती के लिए इसे ऋणात्मक (-1) रखा जाता है।
range() Expression Meaning Generated Sequence
range(5) 0 से शुरू होकर 5 से पहले (4 तक) 0, 1, 2, 3, 4
range(2, 7) 2 से शुरू होकर 7 से पहले (6 तक) 2, 3, 4, 5, 6
range(1, 10, 2) 1 से 9 तक, 2-2 के अंतराल (Step) पर 1, 3, 5, 7, 9
range(5, 0, -1) 5 से उल्टी गिनती 1 तक (0 से पहले) 5, 4, 3, 2, 1
# Printing multiplication table of 5 using for loop with range(): for i in range(1, 11): print("5 x", i, "=", 5 * i)

Topic 10

Jump Statements: break, continue, and pass

कभी-कभी हमें लूप की सामान्य कार्यप्रणाली को बीच में ही बदलने, रोकने या किसी चरण को छोड़ने की आवश्यकता होती है। इसके लिए पायथन तीन Jump / Control Statements प्रदान करता है:

10.1 The break Statement

break स्टेटमेंट का उपयोग लूप को बीच में ही पूरी तरह समाप्त (Terminate) करने के लिए किया जाता है। जैसे ही लूप के अंदर break चलता है, प्रोग्राम का नियंत्रण तुरंत लूप से बाहर निकलकर लूप के बाद वाली लाइन पर चला जाता है।

for num in range(1, 10): if num == 5: print("Found 5! Breaking the loop...") break print(num, end=" ") # Output: 1 2 3 4 Found 5! Breaking the loop...

10.2 The continue Statement

continue स्टेटमेंट पूरे लूप को बंद नहीं करता। यह केवल वर्तमान चक्र (Current Iteration) के शेष कोड को छोड़ देता है और नियंत्रण को तुरंत लूप के अगले चक्र (Next Iteration) की शुरुआत में भेज देता है।

for num in range(1, 6): if num == 3: continue # When num is 3, it skips the print statement below print(num, end=" ") # Output: 1 2 4 5 (Note: Only 3 was skipped, loop did not stop!)

10.3 The pass Statement

पायथन में pass एक Null Statement (शून्य ऑपरेशन) है। जब यह चलता है तो कुछ भी नहीं होता (No-operation)।

इसका उपयोग कब होता है? पायथन में सिंटैक्स के नियम के अनुसार आप किसी if, for, while या def ब्लॉक को अंदर से बिल्कुल खाली नहीं छोड़ सकते (वरना IndentationError आएगा)। यदि आप भविष्य में कोड लिखना चाहते हैं और अभी केवल ढांचा (Skeleton) बनाना चाहते हैं, तो खाली जगह भरने के लिए pass लिख देते हैं।

x = 10 if x > 5: pass # Placeholder: nothing happens here, will add code later else: print("Small number")
Statement Effect on Loop Real-life Analogy
break पूरे लूप को हमेशा के लिए बंद कर देता है और बाहर निकल जाता है। मैच बीच में ही रद्द (Cancel) होकर स्टेडियम से बाहर आ जाना।
continue केवल वर्तमान राउंड को छोड़कर अगले राउंड पर चला जाता है। एक गेंद को वाइड छोड़कर तुरंत अगली गेंद फेंकना।
pass कुछ नहीं करता; केवल सिंटैक्स एरर से बचाने के लिए खाली जगह भरता है। कुर्सी पर बैग रखकर सीट रिज़र्व करना ताकि जगह खाली न दिखे।
